# Techno Campgain — PWA

نمونه رابط کاربری فارسی و راست‌چین برای طراحی و مدیریت کمپین‌های فروش توسن تکنو؛ شامل دو نمای «مدیریت» و «کارگزار».

## قابلیت‌ها

- صفحه آغازین با لوگوی توسن تکنو؛ عنوان فارسی پس از ۵ ثانیه نمایش داده می‌شود.
- نام اپ و آیکن PWA: `Techno Campgain` با لوگوی توسن تکنو.
- داشبورد مدیریت با خلاصه کمپین‌ها، بودجه‌های واردشده، وضعیت کارگزاران و گزارش‌ها.
- ساخت و ویرایش کمپین، ذخیره پیش‌نویس و فعال‌سازی کمپین پس از تکمیل اطلاعات.
- تمام کادرهای عددی بودجه، حدنصاب فروش و پاداش هنگام ایجاد کمپین خالی‌اند؛ مقادیر توسط مدیریت وارد می‌شوند.
- واحد تمام مبالغ مالی «تومان» است.
- افزودن پلکان دلخواه، تعیین نام سطح، حد پایان بازه و مبلغ پاداش هر دستگاه.
- ثبت کارگزار و ثبت/ویرایش تعداد فروش معتبر هر کارگزار برای هر کمپین.
- محاسبه سطح فعلی، پاداش بازه‌های تکمیل‌شده و فاصله تا تکمیل بازه جاری.
- «خط جاری فروش» متحرک در PWA کارگزار با پیام‌های پویا برای تعداد فروش باقی‌مانده، پاداش بازه جاری و سطح بعدی.
- نمایش همان متن خط جاری فروش در فهرست کارگزاران پنل مدیریت.
- گزارش‌های مدیریتی و خروجی CSV از عملکرد کارگزاران.
- ذخیره محلی داده‌ها در مرورگر، آیکن برنامه، manifest و service worker برای نصب و استفاده آفلاین پایه.
- طراحی واکنش‌گرا برای دسکتاپ و موبایل.

## اجرا در محیط محلی

این پروژه نیاز به فرایند build یا نصب کتابخانه ندارد.

با Python:

```bash
python -m http.server 8080
```

سپس این آدرس را باز کنید:

```text
http://localhost:8080
```

برای کارکرد Service Worker و نصب PWA، پروژه را از طریق `localhost` یا یک میزبان HTTPS اجرا کنید؛ بازکردن مستقیم فایل `index.html` برای قابلیت‌های PWA کافی نیست.

## انتشار با GitHub Pages

1. محتویات این پوشه را مستقیماً در ریشه مخزن GitHub قرار دهید.
2. تغییرات را commit و push کنید.
3. در بخش **Settings → Pages**، منبع انتشار را روی شاخه موردنظر و پوشه `/ (root)` قرار دهید.
4. پس از انتشار، آدرس Pages را در مرورگر باز کنید. برای نصب، از گزینه نصب برنامه در مرورگر استفاده کنید.

## استفاده اولیه

1. از صفحه ورود، «پنل مدیریت» را انتخاب کنید.
2. از بخش «طراحی کمپین» نام و بودجه را وارد کنید.
3. در جدول پلکان‌ها حد پایان بازه‌ها و پاداش هر دستگاه را وارد کنید. حد پایان آخرین پلکان خالی می‌ماند تا آن پلکان از نقطه شروع خود به بعد ادامه یابد.
4. کمپین را ابتدا به‌صورت پیش‌نویس ذخیره کنید یا پس از تکمیل مقادیر آن را فعال کنید.
5. از بخش «کارگزاران» کارگزار اضافه کنید و تعداد فروش معتبر او را برای کمپین ثبت کنید.
6. از طریق «تغییر دسترسی» به نمای کارگزار بروید و خط جاری فروش، سطح و پاداش را مشاهده کنید.

## نکات فنی مهم

- این نسخه یک **پروتوتایپ PWA سمت مرورگر** است. داده‌ها در `localStorage` همان مرورگر ذخیره می‌شوند؛ بین دستگاه‌ها یا کاربران مختلف همگام‌سازی نمی‌شوند.
- انتخاب نقش مدیریت/کارگزار برای بررسی تجربه کاربری است و احراز هویت امن محسوب نمی‌شود. برای استفاده عملیاتی چندکاربره باید احراز هویت، سطح دسترسی و ذخیره‌سازی سمت سرور اضافه شود.
- فروش هر کارگزار برای کمپین انتخاب‌شده توسط مدیریت وارد می‌شود؛ این نسخه به سامانه فروش یا منبع تراکنش واقعی متصل نیست.
- CSS، فونت `Yekan` را در اولویت قرار می‌دهد. فایل باینری فونت در این بسته قرار نگرفته است؛ اگر Yekan روی دستگاه نصب نباشد، مرورگر از فونت جایگزین فارسی استفاده می‌کند. برای نمایش یکسان روی همه دستگاه‌ها، باید نسخه مجاز فونت در محیط انتشار فراهم شود.
- ساختار پاداش برای هر کمپین قابل تنظیم است. نرخ هر دستگاه بر اساس بازه فروش مربوط محاسبه می‌شود؛ نرخ سطح جدید به دستگاه‌های بازه‌های قبلی تسری پیدا نمی‌کند. پاداش بازه‌های دارای حدنصاب پس از تکمیل و تأیید آن بازه قابل پرداخت است؛ نرخ آخرین پلکان برای دستگاه‌های آن بازه ادامه پیدا می‌کند.
